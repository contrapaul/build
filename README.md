# build.contrapaul.com

A talk and a guide in one site: how I actually build learning websites with
AI. Four tabs: the Talk, a Start guide to your first website, Projects, and a
Glossary.

Plain static files, no build step. Served by Cloudflare Pages from this repo.

```
python3 -m http.server 8000
```

Then open http://localhost:8000.

- [PLAN.md](PLAN.md): the brief and the plan
- [HANDOFF.md](HANDOFF.md): where things stand
- [CLAUDE.md](CLAUDE.md): the rules any AI agent working here follows
